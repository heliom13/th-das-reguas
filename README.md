# Barbearia TH das Réguas

Site estático da Barbearia TH das Réguas (São Luís, MA): serviços e preços, agendamento pelo WhatsApp, cursos de barbeiro e loja da touca de reflexo.

Sem build: é só `index.html` + pasta `img/`.

## Rodar local
Abra o `index.html` no navegador.

## Publicar no Render
New → Static Site → escolha este repositório.
- Build Command: deixe vazio
- Publish Directory: `.`

## A trocar pelos dados reais
- Endereço e horários (rodapé)
- Preços dos serviços, cursos e touca (no `<script>` e nos cards)
